# Secret Pal — 심플 마니또 프로토타입

## 실행
`index.html`을 Chrome/Edge에서 열면 실행됩니다.

## 포함된 기능
- 심플하고 미니멀한 참가자 화면 / 별도 관리자 탭
- 닉네임 로그인과 모임 코드
- 관리자 번호로 모임 생성 및 관리자 로그인
- 개인별 마니또 확인
- 선행 메시지 작성 및 관리자 통합 목록
- 마니또 추측 1회 제출, 참가자에게 정답 여부 미공개
- 관리자 화면에서 정답/오답 확인
- 추첨 및 재추첨, 관리자 CSV 다운로드
- 참가 링크 복사

## 반드시 알아둘 제한
이 버전은 브라우저 `localStorage`를 사용하는 **로컬 프로토타입**입니다. 여러 기기/사용자 사이에 데이터를 공유하지 못하며, 코드/결과가 클라이언트 쪽에 저장됩니다. 따라서 실제 모임에서 비밀을 보장하는 운영 서비스로 공개해서는 안 됩니다. 실제 온라인 운영에는 서버/DB, 서버 측 인증과 권한 검증이 필요합니다.

개인 링크는 `?room=모임코드` 형태를 지원합니다. 실제로 여러 참가자에게 공유하려면 온라인 배포와 데이터베이스 연결이 필요합니다.
